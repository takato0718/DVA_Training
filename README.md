# DVA_Training
[アプリはこちら](https://takato0718.github.io/DVA_Training/)
## アプリ概要
このアプリは動体視力を鍛えるためのゲームです。
一般的に動体視力は20歳前後をピークに徐々に衰え始め、40代から低下が加速し、60代以降で急激に低下する傾向にあります。また、動体視力が衰えると車での事故なども増えてしまいます。
それを防ぐためのトレーニングとして開発されたのがこのアプリです。
## 使い方
スタートボタンを押すとカウントダウンが始まり文字が流れます。その文字がなんであったかを文字が流れた後に出てくるテキストボックスに入力し、その正答数を見ることができます。注意点として、カウントダウンがあるのは初めだけで、そのあとは回答確認をしてすぐに次の問題が流れます。
